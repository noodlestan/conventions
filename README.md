# @noodlestan/conventions

`@noodlestan/conventions` is a small reference package for reusable Noodlestan
conventions. The repository contains the convention documents and an inventory
of their ownership and relationships.

The current document layout is intentionally minimal: [index.md](index.md) is
the inventory shell, while convention documents will be added under their
approved package boundaries in a later migration.

The repository is maintained as a standalone reference source. Its package
metadata remains private until publication and consumer-installation decisions
are explicitly made.
